- 불필요한 port별 catalog, 예시 payload catalog, schema 생성 로직, request event catalog 제거
- `DEVS_MODELING_GUIDE.md`에 통합 메시지 사용 기준 추가

## Notes

- 실제 DEVS 이벤트에는 `MESSAGE_JSON`의 복사본 dict만 전달한다.
- `git diff --check -- modeling/message/message.py`는 통과했다.
