## Current Model Behavior

### ManufacturingManage

- `m_req_from_MCS`: 요청된 `product`, `what`에 맞는 WH 실대차 자재데포 위치를 `m_info_to_MCS`로 출력
- `item_update_from_gen`: WH 실대차 자재데포 상태를 메모리에서 갱신한 뒤 위치 정보를 `m_info_to_MCS`로 출력
- `cmd_completed_from_amr`: AMR 도착 정보를 기준으로 자재/공정 작업 정보를 `work_info_to_analyzer`로 출력
- 공정데포 도착이면 `arrive_to_wk`로 Worker에 도착 정보를 전달

### Worker

- `arrive_from_mm`: 공정데포 도착 정보를 받음
- `WORK` 상태에서 `work_time`만큼 대기
- 같은 `product`, `what`에 맞는 ML `R` 노드를 회수데포로 찾아 `item_depot_update_to_MCS`로 출력

### TransportationManager

- `return_completed_from_amr`: AMR별 상태를 내부 `amr_fleet`에 저장하거나 갱신
- `amr_req_from_ACS`: 현재 저장된 AMR 중 IDLE 상태인 AMR만 골라 `amr_info_to_ACS`로 출력
- IDLE 판단 기준:
  - `amr_status == 'IDLE'`
  - 또는 `idle_type == 'RETURN_IDLE'`

## Important Notes

- `transportation_manager.py`는 초기 AMR 목록을 하드코딩하지 않는다. 따라서 초기 AMR 상태 입력이 없으면 첫 `amr_req_from_ACS` 응답은 빈 리스트가 된다.
- 현재 메시지 표준은 `AMR_id`이며, Python 예약어인 `from`은 `Message.from_`로 저장되고 `to_dict()`에서 `from`으로 직렬화된다.
- WH의 `O` 또는 `0` rack은 실대차 위치, `X` rack은 공대차 위치로 처리한다.
- ML의 `R` 노드는 회수데포, `P` 노드는 공정데포로 처리한다.
- Python 실행기가 현재 환경 PATH에 없어 import 또는 compile 검증은 실행하지 못했다.
